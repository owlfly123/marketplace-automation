# Итоги по финансовым отчётам Wildberries

## Задача
Каждую неделю WB присылает детализацию отчёта комиссионера на 20–50 тыс. строк. Чтобы получить итог по продажам, сумме к перечислению и рознице, нужно было открыть каждый файл, просуммировать колонки и вычесть возвраты.

## Решение
Приложение (Python + pandas + tkinter): выбираешь сразу несколько отчётов, указываешь номера колонок, получаешь итоги и копируешь их в буфер одной кнопкой.

- Возвраты определяются по колонке «Тип документа» и вычитаются.
- Понимает числа в любом формате: `123 456,78`, `123,456.78`, неразрывные пробелы.
- Читает только нужные колонки, поэтому большие файлы обрабатываются быстро.
- Номера колонок для отчёта из ЛК и для выгрузки по API разные; они записаны в [COLUMNS.md](COLUMNS.md).

**Результат:** экономия 1–2 часа в неделю.

## Запуск
```bash
pip install -r requirements.txt
python wb_summarizer.py
```
