# Исходный промпт (техническое задание)

Этот текст я писала для ИИ-агента в Cursor: каждую неделю он по нему собирал план отгрузки.
Позже на его основе написан самостоятельный скрипт `wb_order_planner.py`, которому ИИ уже не нужен.

---
Подготовь Excel-план отгрузки WB по 4 регионам на основе недельных отчетов и файла «в пути».
### 1) Источники данных и папка
Работай с файлами в папке `C:\Work`.
В папке могут быть файлы с именами на кириллице/латинице и «битым» отображением в консоли (из-за кодировки).  
При выборе файлов ориентируйся **не на визуальную кириллицу**, а на **даты в имени файла**.
### 2) Какие файлы брать
Нужно брать:
1. **4 последних недельных отчета продаж** (по датам периода в имени файла), где есть лист `Детальные данные`.
2. **Актуальный файл “в пути”** (например, `В пути 07.05.xlsx`, `В пути 23.04.xlsx` и т.п.).
Если имена в консоли выглядят искаженно (`����`), файл все равно валиден — используй путь через glob/маску и работай дальше.
---
### 3) Нормализация регионов (критично)
В продажах встречаются варианты:
- `Южный + Северо-Кавказский`
- `Южный и Северо-Кавказский`
Оба варианта считать одним регионом: **Yuzhny (Южный)**.
Полная карта регионов:
- `Южный + Северо-Кавказский` И `Южный и Северо-Кавказский` → `Yuzhny`
- `Приволжский` → `Privolzhsky`
- `Северо-Западный` → `Severo-Zapadny`
- `Уральский` → `Uralsky`
---
### 4) Из каких колонок брать данные в недельных файлах
Лист: `Детальные данные`  
Колонки:
- `Артикул продавца`
- `Название`
- `Регион`
- `Итого заказов, шт`
- `Остатки склад ВБ, шт`
Правила:
- Заказы по SKU суммируй по неделям отдельно (`w1..w4`).
- **Остатки WB брать только из самого последнего недельного файла** (w4).
---
### 5) Как учитывать файл “в пути”
В файле “в пути”:
- SKU = колонка `ID2` (обычно 4-я колонка)
- Количество в пути = колонка `Количество` (обычно 7-я колонка)
Сопоставь листы файла “в пути” с регионами по названию листа:
- если лист называется `Yuzhny` или `Южный`/`Южный и Северо-Кавказский` → `Yuzhny`
- `Privolzhsky` или `Приволжский` → `Privolzhsky`
- `Severo-Zapadny` или `Северо-Западный` → `Severo-Zapadny`
- `Uralsky` или `Уральский` → `Uralsky`
Если какого-то листа по региону нет, считать `в пути = 0`.
---
### 6) ABC-анализ
Делай ABC **отдельно по каждому региону**:
1. Для каждого SKU: `Total = w1+w2+w3+w4`.
2. Сортировка SKU по `Total` по убыванию.
3. Кумулятивная доля:
   - A: до 80%
   - B: до 95%
   - C: остальное
4. В итоговый план включать **только группу A**.
---
### 7) Расчет спроса, всплесков и роста
Для каждого SKU (в группе A):
#### 7.1. Обнаружение краткосрочного всплеска (yellow)
- `m = max(w1,w2,w3,w4)`
- `avg_rest = average(остальные 3 недели)`
- Если `m >= 3 * avg_rest`, считать это краткосрочным всплеском:
  - исключить неделю-спайк из расчета базового спроса (`used = rest`)
  - пометить строку как yellow / комментарий: `Исключен краткосрочный всплеск спроса`
#### 7.2. Устойчивый рост (green)
Если `w1 < w2 < w3 < w4` и `w1 > 0`, считать устойчивый рост:
- включить коэффициент роста  
\[
k = \min(1.6,\sqrt{w4/w1})
\]
- пометить строку green / комментарий: `Устойчивый недельный рост спроса`
#### 7.3. Base / April daily demand
- `base_week = average(used_weeks)` (после исключения спайка, если был)
- `Base daily demand = base_week / 7`
- `April daily demand = Base daily demand * 0.8`
- Если есть устойчивый рост, умножить дополнительно на `k`.
---
### 8) Рекомендация к поставке
Горизонт покрытия:
- `30 дней запаса + 12 дней логплечо = 42 дня`
Формула:
\[
Need = \lceil \max(0,\; AprilDaily \cdot 42 - StockWB - InWay)\rceil
\]
Где:
- `StockWB` — остатки из последней недели (w4),
- `InWay` — количество в пути по SKU и региону.
---
### 9) Структура итогового файла
Сделай один Excel с 4 вкладками:
- `Yuzhny`
- `Privolzhsky`
- `Severo-Zapadny`
- `Uralsky`

Колонки:
1. `Артикул продавца`
2. `Название`
3. `Остатки склад ВБ, шт.`
4. `В пути, шт`
5. `Итого заказов, шт`
6. `Рекомендованное количество к поставке, шт.`
7. `Base daily demand`
8. `April daily demand`
9. `Заказы <неделя1>, шт`
10. `Заказы <неделя2>, шт`
11. `Заказы <неделя3>, шт`
12. `Заказы <неделя4>, шт`
13. `ABC`
14. `Коэффициент роста (k)`
15. `Комментарий`
Сортировка строк: по `Рекомендованное количество к поставке, шт.` по убыванию.
---
### 10) Цветовые пометки
- Желтая заливка строки: краткосрочный всплеск (`yellow`).
- Зеленая заливка строки: устойчивый рост (`green`).
- Если и всплеск, и рост — можно комбинировать комментарием:
  `Исключен краткосрочный всплеск спроса; устойчивый рост`.
---
### 11) Проверки качества перед сохранением
Сделай sanity-check:
1. В каждом регионе есть строки с ненулевым `Остатки склад ВБ, шт.` (если в исходнике они есть).
2. `В пути, шт` не весь нулевой, если в файле “в пути” есть соответствующие листы/SKU.
3. Для 2–3 SKU в регионе проверить вручную:
   - суммы недель,
   - остаток из последней недели,
   - `in way`,
   - итог `Need`.
Сохрани файл в ту же папку `C:\Work` с именем вида:
`WB_order_plan_<дата>_with_in_way.xlsx`.
