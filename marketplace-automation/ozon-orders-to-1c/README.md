# Заказы Ozon → формат загрузки в 1С

## Задача
Заказы из личного кабинета Ozon приходят отдельными файлами. Раньше менеджер открывал каждый, копировал артикулы и количество и переносил в шаблон для 1С.

## Решение
PowerShell-скрипт: выбираешь папку, и все файлы в ней обрабатываются за один запуск.

- Читает CSV (разделители `;` `,` Tab, кодировки UTF-8 и Windows-1251) и XLSX.
- Пропускает служебные строки, берёт нужные колонки, добавляет ИНН/КПП покупателя.
- Числа сохраняет как числа, коды — как текст (без потери ведущих нулей).
- Имя результата берётся из номера заказа в файле; существующие файлы не перезаписываются.
- В конце показывает сводку: сколько обработано и что не удалось.

**Результат:** экономия 2–4 часа в неделю.

## Запуск
Двойной клик по `run_batch.cmd` (Windows, нужен установленный Excel). ИНН/КПП задаются в начале `make_batch.ps1`.
